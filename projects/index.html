食序 AI 食养助手

项目负责人

问题

饮食管理缺少个性化与持续反馈，用户难以把健康建议转化为日常行动。

方案

设计“状态问答 - Agent 推荐 - AI 报告 - 健康档案”的闭环，并基于 Dify 搭建食养推荐 Agent。

结果

完成从方案设计到评测验证的全链路落地，沉淀 RAG 知识库与 LLM-as-a-Judge 评测流程。

Dify 搭建RAG 知识库大模型评测健康食养

天网寻踪无人机搜救

项目负责人

问题

搜救任务中案件信息分散、区域划定和多角色协同复杂，影响搜救效率。

方案

设计覆盖案件管理、搜寻区域、航线规划和任务执行的调度 Agent 与服务系统。

结果

输出调度方案、App 原型与服务系统设计，项目获中国研究生未来飞行器创新大赛三等奖。

Agent 设计服务设计低空搜救界面体验
